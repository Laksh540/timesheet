# Timesheet Management App

A simple timesheet management application built using React and TypeScript.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* React Hook Form
* JSON Server

## Node Version


## Setup

Install dependencies:

```
npm install
```

Run frontend:

```
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

Install backend dependencies:
open another terminal window in vs code then
cd server
npm install
cd ..

Run mock backend:

```
npm run mock-server
```


## Environment Variable

Create a `.env` file:

VITE_API_URL=http://localhost:3000


## Notes

* JSON Server is used as a mock backend.
* Seed data is generated when the app starts.
* Authentication is mocked for demo purposes.
